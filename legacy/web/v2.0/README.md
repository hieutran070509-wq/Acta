# ACTA v2.0

The release that gave the project its permanent identity.

## Overview

Version 2.0 represents the most significant conceptual transition in ACTA's history.

While Version 1.0 proved that the original Action Logger concept could work on the web, Version 2.0 focused on defining what the product should ultimately become.

This release introduced the permanent name **ACTA** and established many of the principles that continue to guide development today.

More importantly, the project moved beyond being a simple action logger and began evolving into a complete action-centered productivity platform.

Many of ACTA's long-term systems, progression mechanics, and architectural foundations originated in this version.

---

## Objectives

The primary goals of Version 2.0 were:

- Establish ACTA as the permanent project identity
- Replace the original SP system with AP
- Introduce long-term progression
- Expand beyond local-only productivity tracking
- Build the foundation for cloud-connected experiences
- Improve usability across desktop and mobile devices
- Create a more scalable architecture for future development

Rather than focusing on feature quantity, this version focused on redefining the product itself.

---

## Major Features

Version 2.0 introduced several major systems and redesigns:

- Project renamed from **Action Logger** to **ACTA**
- SP replaced by AP (Action Points)
- RPG-inspired level progression
- Achievement system
- User profiles
- Cloud synchronization
- Multi-language support
- Integrated To-do List
- Responsive mobile interface
- Improved visual feedback
- Modernized user interface
- Expanded statistics and progression systems

Together, these additions transformed ACTA from a lightweight action logger into a more complete productivity platform.

---

## Design Philosophy

One of the most important decisions in Version 2.0 was replacing **Score Points (SP)** with **Action Points (AP)**.

Earlier versions attempted to assign values to different actions.

This quickly introduced difficult questions:

- How much is reading worth?
- Should studying be worth more than exercising?
- Who decides the value of an action?

No universal answer existed.

Version 2.0 therefore shifted away from evaluating actions and toward recognizing them.

AP became a measure of participation and consistency rather than perceived importance.

This change aligned more closely with ACTA's emerging philosophy:

> Recognition over evaluation.  
> Actions over intentions.

The goal was no longer to score life.

The goal was to acknowledge meaningful action.

- Localization-ready interface
